# Variable Reference (Masked)

Before reproducing, replace every `<PLACEHOLDER>` below with your own values.
**No real values appear anywhere else in this documentation.**

| Placeholder | Meaning | Example / Notes |
|---|---|---|
| `<USER>` | Uniform username on both machines (keep UID/GID identical, e.g. 1000) | e.g. `aiuser` |
| `<HOSTNAME_A>` | Head node hostname | e.g. `spark-a` |
| `<HOSTNAME_B>` | Worker node hostname | e.g. `spark-b` |
| `<IP_MGMT_A>` | Head management IP (the address you SSH to) | same LAN |
| `<IP_MGMT_B>` | Worker management IP | same LAN |
| `<MGMT_IF>` | Management interface (NCCL bootstrap; must match on both nodes) | wired `enP7s7` or Wi-Fi `wlP9s9` |
| `<IP_FABRIC_A>` | Head fabric IP (generated by Cluster Assistant) | e.g. `10.100.192.1` |
| `<IP_FABRIC_B>` | Worker fabric IP | e.g. `10.100.192.2` |
| `<IP_FABRIC_A2>` / `<IP_FABRIC_B2>` | Second-link IPs (companion subnet) | e.g. `10.100.193.1/2` |
| `<NCCL_HCA_A>` | Head RoCE device (depends on which physical port the cable is in) | `rocep1s0f0` or `rocep1s0f1` |
| `<NCCL_HCA_B>` | Worker RoCE device | can differ from head |
| `<NCCL_IF_A>` | Head RoCE netdev | `enp1s0f0np0` / `enp1s0f1np1`, etc. |
| `<NCCL_IF_B>` | Worker RoCE netdev | can differ from head |
| `<WIFI_SSID>` / `<WIFI_PASS>` | (optional) management Wi-Fi | omit if using wired |
| `<PROXY_HOST>` / `<PROXY_PORT>` | (optional) proxy server address/port | only needed on restricted networks |
| `<PROXY_USER>` / `<PROXY_PASS>` | (optional) proxy credentials | only if the proxy requires auth |
| `<HF_MODEL>` | HuggingFace model id | `deepseek-ai/DeepSeek-V4-Flash-0731` |
| `<HF_MODEL_SHORT>` | Model id without the org prefix (used in local paths) | `DeepSeek-V4-Flash-0731` |
| `<IMAGE>` | vLLM runtime image | `ghcr.io/anemll/dspark-vllm-gx10:0.1.1` |

## Measured Network Facts (China mainland)

| Target | Direct | Via proxy | Conclusion |
|---|---|---|---|
| huggingface.co | blocked | ~0 MB/s | use `hf-mirror.com` directly |
| hf-mirror.com | ~27 MB/s | — | 30–40 MB/s with chunked parallelism |
| Xet protocol (cas-bridge) | 403 | 403 | must set `HF_HUB_DISABLE_XET=1` |
| ghcr.io (API) | fast | slow/unstable | API works direct |
| ghcr.io (blob downloads) | throttled ~17 KB/s | unstable | use `ghcr.nju.edu.cn` mirror (~24 MB/s, identical digests) |

> On open (non-China) networks, use the official sources; chapter 06 gives the alternative commands.
